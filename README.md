# Rostar - إدارة الشيفتات

واجهة ويب عربية RTL لإدارة روستر التمريض. تعمل محليًا عبر LocalStorage دون Firebase، ويمكن ربطها بـ Firestore بعد إدخال إعدادات المشروع.

## التشغيل السريع على Termux

```bash
pkg update
pkg install python git -y
cd ~/smart-nurse
python -m http.server 8080
```

افتح `http://127.0.0.1:8080` في المتصفح. لأن المشروع يستخدم ES Modules، لا تفتح `index.html` مباشرة من مدير الملفات.

## تجربة التطبيق

- كود الإدارة التجريبي: `ADMIN123`
- من لوحة الإدارة اختر **تعبئة بيانات تجريبية**.
- أكواد الممرضين التجريبية: `N001`, `N002` ... `N012`.
- بيانات التجربة محفوظة محليًا في المتصفح على نفس الجهاز والمتصفح.

## ربط Firebase

1. أنشئ Firebase project وأضف Web App.
2. افتح `app.js` واستبدل قيم `firebaseConfig` بالقيم الحقيقية.
3. فعّل Cloud Firestore وأنشئ قاعدة البيانات.
4. اكتب قواعد Firestore آمنة قبل إدخال بيانات حقيقية. ملف `firebase.rules.example` مقفول افتراضيًا عمدًا.
5. جرّب تحميل/حفظ البيانات بعد نشر القواعد الصحيحة.

المجموعات المستخدمة:
- `nurses`
- `nurseSchedules`
- `publishedRosters`

## النشر على GitHub Pages

ارفع الملفات إلى مستودع GitHub ثم Settings → Pages → Deploy from a branch → `main` و`/(root)`.
يمكنك النشر أيضًا عبر Firebase Hosting.

## ملاحظات مهمة قبل الاستخدام الحقيقي

- `ADMIN123` تسجيل دخول تجريبي داخل الواجهة فقط، وليس حماية أمنية. لا تستخدمه لحماية بيانات حقيقية.
- كود الممرض وحده لا يوفر مصادقة قوية. للإنتاج استخدم Firebase Authentication أو Backend موثوقًا مع صلاحيات Admin.
- الجدول المجمع يعرض أسماء Senior وStaff ويعلّم خانة السنيور عند عدم وجود سنيور واحد بالضبط. العدد المستهدف لأفراد Staff يحتاج مراجعة حسب سياسة القسم.
- زر الطباعة يستخدم نافذة الطباعة في المتصفح ويمكن اختيار Save as PDF.
- الإشعارات الفورية FCM والتنبيهات المجدولة غير مفعلة في هذه النسخة؛ يلزم إعداد خدمة موثوقة وإذن إشعارات.
- يجب مراجعة تعارضات الراحة بين الشيفتات يدويًا قبل اعتماد الجدول النهائي.
